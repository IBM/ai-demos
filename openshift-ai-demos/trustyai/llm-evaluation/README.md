# LLM Evaluation

Evaluate Large Language Models against standardized benchmarks and datasets on Red Hat OpenShift AI.

---

## Available Frameworks

### LM-Eval Framework
Integration of popular open-source evaluation toolkits like `lm-evaluation-harness` to run benchmark evaluations against deployed model InferenceServices.

- **Available Demos**:
  - **Eval Quickstart**: Deploy a Phi-3 model and run an `Arc-Easy` science-question evaluation job using an `LMEvalJob` custom resource.
