# Generative Models

Generative models are AI models that generate new content, such as text, images, code, and audio, by learning patterns from existing data. Large Language Models (LLMs) are a type of generative model designed to understand and generate human-like text.

This demo demonstrates how to deploy and serve a Large Language Model (LLM) on Red Hat OpenShift AI. It provides a simple, production-ready example of model serving, enabling users to run inference requests through a scalable and efficient deployment.
